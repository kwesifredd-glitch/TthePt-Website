# Root Archive Directory

This directory stores archived modules, components, and controllers that have been removed from the active Admin Portal navigation and kept in the root files for reference, record-keeping, and cold configuration.

## Archived Components & Modules:
1. **Archive Vault (`AdminArchive.tsx`)**
   - The unified tab container with module switcher for accessing archived administrative tooling.
2. **Payment Gateways & Webhooks (`AdminGateways.tsx`)**
   - Stripe, PayPal, and Paystack integration management, webhook URLs, and manual payload testing/simulation.
3. **Site Content Manager (`ContentManager.tsx`)**
   - Homepage hero narrative, subtitle, and dynamic text controller.
